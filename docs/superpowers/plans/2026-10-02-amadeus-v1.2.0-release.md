# Amadeus v1.2.0 Implementation and Release Plan

> Execute in the existing upgrade worktree, with an independent code review before merging main. The user authorized implementation, integration, tests and publication; proceed through the release without another approval checkpoint.

**Goal:** Publish v1.2.0 with DSH 0.2.0-rc.2, the merged fork improvements, native file browsing and PDF selection, and repaired queue rendering.

**Architecture:** Keep the four plugins. DSH owns the files tab, listing, expansion, ordering, watch feeds and preview navigation. Amadeus wraps the registered native component only to attach transfer/delete/editor actions to stable `data-files-*` hooks; it does not register a competing files kind or maintain a second tree. Remove the obsolete queue wrapper and fixed PDF selection color. Preserve main's Safari/PWA, source-reference, editor cache and documentation changes.

**Tech Stack:** Node 24, React 18, Cordis, DSH 0.2.0-rc.2, Playwright, Docker, code-server 4.104.2, GitHub CLI.
