# DSH 0.2.1-alpha.1 / RC1 升级审计

日期：2026-10-04。Amadeus 与四个插件保持 `1.2.0-rc.1`。

## 版本与来源

- 原基线：`main@9177201`，DSH/WebServer `0.2.0-rc.2`。
- 目标：[dsh-v0.2.1-alpha.1](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-alpha.1)，精确提交 `5badb15009ae1756c3afe0ae0cef1faafc290ccc`。
- DSH/WebServer 与四个 DSH peer 固定为 `0.2.1-alpha.1`；Cordis/Schemastery 对齐上游为 `4.0.5-alpha.1` / `3.18.5-alpha.1`。
- 旧锁文件增量安装出现 Cordis peer 冲突；以相同工作区 manifests 在干净目录解析锁文件，再执行 `npm ci`。没有使用 `--force` 或 `--legacy-peer-deps`。

## 原生替代与保留边界

| 项目实现/集成 | 处理与证据 |
| --- | --- |
| Safari 原生构造器补丁 | 删除脚本、启动调用及补丁测试。上游 `dsh-util-values` 使用当前引擎原生构造器作比较，Chromium/WebKit 直接验证未修改的模块，跨 iframe 的 Object/Array 可通过、自定义对象被拒绝。 |
| PDF/Office 自建渲染器与文件树样式 | 清理前次迁移遗留的 PDF textLayer、分页、树排序/行样式和旧注释卡片规则；原生控件、主题选区、自然排序、监听和预览继续交给 DSH。 |
| 插件样式、bundle/HMR 依赖映射 | 使用上游修复；没有新增项目补丁。Amadeus 自身样式仍按插件 effect 生命周期移除。 |
| Automation | 使用 Web 内置组合及其模式范围。项目没有 schedule shim、invariant 插件或旧 stats 行覆盖，无需另设替代实现。 |
| 聊天输入 IME seed | 保留。临时停用补丁后，真实 Chromium CDP `Input.imeSetComposition` 在首字符 `n` 上产生选区；恢复 NBSP seed 后连续输入与中文提交通过。上游目标/队列编辑器的 IME 修复没有覆盖此问题。 |
| Safari 缺失 API、PDF worker、触屏/PWA | 保留。上游及嵌入 PDF worker 仍调用部分较旧 WebKit 没有的 API；构造器检查修复不能替代这些跨 realm polyfill 与手势防护。 |
| 品牌/会话最小宽度、code-server/LaTeX 补丁 | 保留。它们提供 Amadeus 品牌、布局、编辑文档同步和代理路径支持，上游未提供等价能力。 |
| Basic Auth、文件传输/删除确认、注释、PWA | 保留。均为 Amadeus 独立功能。`--public-url` 由原生 CLI 处理，当前 Amadeus 绝对路由/PWA 仍要求部署在源站根路径。 |

## 注释引用修复

用户报告回答中的 `[注释 1]` 未渲染为按钮。旧实现只查询 `locations.getTurn()`，而开启回合的用户消息可能在 `turn/start` 之前，缺少该回合的 location。改为从 `snapshot.order` 与 `snapshot.nodes` 按事件位置寻找回答前最近的用户/steering 消息，普通新请求同时清除旧注释上下文。

保留原生聊天节点语义和渲染器。浏览器回归覆盖实际 Reader 组件的引用渲染、流式正文变化、悬浮出处、点击参数、异步加载后的定位与高亮，以及后续普通消息不继承旧引用。文件回跳先将懒加载占位页滚入视口，再等待 textLayer/正文加载，保留起止页并兼容 PDF 空白差异；每次点击具有独立导航请求 ID，允许重复定位同一条引用。

RC1 原地重建使用新的 PWA 缓存修订 `amadeus-pwa-1.2.0-rc.1-dsh-0.2.1-alpha.1`。激活时删除旧 Amadeus 缓存、保留其他应用缓存；不会强制重载编辑中的页面。

## 发布与验证

当前与全部历史说明统一使用 `New Features`、`Bug Fixes`、`Improvements`、`Chores` 分类、英文条目与可点击贡献者署名；补齐此前缺失的 `1.0.2`。四个插件包与 SHA256 校验随现有 RC1 一起更新。历史 tag/附件不作代码升级。

运行记录位于忽略的 `test-results/`。Windows Node 测试 78 项通过、1 项 POSIX 文件名检查按平台跳过；Linux 79/79 通过。四插件构建、打包及独立 SHA256/包 metadata 校验通过。Chromium/WebKit 兼容、原生文件树操作、插件卸载、编辑器外观/工作台生命周期及真实 code-server 外部写入/原子替换/未保存保护回归通过。注释浏览器回归另覆盖 IntersectionObserver 限定的远页加载与跨页定位；独立代码复核的两项遗漏已修复并复核确认。最终镜像完整部署回归通过：认证/PWA manifest、XeLaTeX、实际中文 IME、原生 PDF 主题选区与缩放、LibreOffice Office 转换、真实编辑器/活动栏/侧栏/状态栏颜色，以及 DSH 到 code-server 的文件打开。最终记录为 `test-results/deployment-dsh-0.2.1-alpha.1.log`，退出码 0。

已观察到的环境限制：Docker Desktop 首次会话/设置持久化可能超过默认 30 秒等待，原生 Office 初始化/转换/PDF 加载链可能超过单项 60 秒等待，部署测试等待真实页面完成写入后继续。无图形桌面的 Debian 容器缺少系统文件管理器图标；上游原生 open-in-app 菜单请求该资源得到 404 并使用 fallback，这一精确路径在回归中单独识别。

真实 iPad/Safari 硬件、用户历史数据卷和外部模型调用不属于本次自动验证样本。
