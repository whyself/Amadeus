# Amadeus v1.2.0-rc.1

本次发布改为候选版 RC1。

## 更新内容

- DSH 与 WebServer 升级并固定到 **0.2.0-rc.2**。该上游依赖仍是预发布候选版。
- 文件浏览、自然排序、目录展开、自动刷新和预览导航采用 DSH 原生文件树。保留文件/文件夹上传、ZIP 下载、重名替换、删除确认及 code-server 编辑入口，删除重复的列表与轮询实现。
- 删除读取旧 `state.queue` 字段的队列包装，修复输入区异常；PDF/Office 选区使用上游主题颜色。
- 纳入 main 已合并的 Safari/PDF worker 兼容、触屏手势防护、注释出处链接、编辑器工作台恢复和部署教程。识别并保留 DSH 0.2 已修复的 Safari 原生构造器检查。
- 修复 POSIX 文件名中的反斜杠被误当成目录分隔符的问题；删除确认绑定准确文件与当前版本。
- 四个插件与 PWA 缓存统一为 **1.2.0-rc.1**，插件元数据声明经过验证的 DSH 版本。
- 恢复编辑器背景的浅色、深色和跟随系统设置，兼容 DSH 0.2 的图标接口，并沿用旧版保存的选择。

## 升级

升级前保存编辑器内容，备份配置、工作区和数据卷。保持原 Compose 项目名与挂载路径，切换到 `v1.2.0-rc.1` 后重新构建：

```bash
git fetch --tags
git switch --detach v1.2.0-rc.1
docker compose up -d --build
```

更新后保存内容并刷新浏览器。自动化任务在 DSH 0.2 中由可选 schedule bundle 提供；此前用旧 patch 开启的用户需在插件管理中确认启用状态。上游模型目录删除了部分旧模型 ID，必要时重新选择模型。

## 发布附件

Login、Files、Reader、Editor 四个 `1.2.0-rc.1` 插件包，以及 `SHA256SUMS`。推荐依照仓库的 [部署教程](https://github.com/whyself/Amadeus/blob/v1.2.0-rc.1/docs/guide-deployment.md) 使用完整工作台。

## 验证

- Linux：81/81 单元测试通过；Windows：80 项通过，1 项 POSIX 文件名测试按平台跳过。
- Chromium 与 WebKit 兼容回归、原生文件树上传/下载/删除/监听、插件卸载生命周期及编辑器工作台恢复回归通过。
- Docker 构建、真实 code-server 失焦刷新与未保存修改保护、DSH 到编辑器的文件打开、XeLaTeX 编译、LibreOffice 转换、原生 PDF 选区/缩放、中文 IME 和 PWA 检查通过。
- 编辑器背景设置使用实际 DSH 导出校验，偏好保留、刷新、系统颜色变化及真实 code-server 背景切换回归通过。
- 四个插件包的版本与 SHA256 校验通过。完整结果见 [Linux 验证](https://github.com/whyself/Amadeus/actions/runs/37024198665)。

容器验证使用新建的测试工作区与数据目录；真实 iPad/Safari 设备和用户历史数据卷未作为本次自动回归样本。
